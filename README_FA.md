# تست مستقل PostgreSQL برای V16 سایکوپلن

این بسته **نصب سایت نیست**؛ یک مخزن آزمایشی مستقل با مدل‌ها و کدهای V16 و داده‌های کاملاً ساختگی است.

- اجرا فقط در GitHub Actions با `workflow_dispatch` و سرویس PostgreSQL 17 موقت.
- هیچ توکن یا آدرس دیتابیس تولیدی در فایل‌ها وجود ندارد؛ کد آزمون اتصال به دیتابیس غیرمحلی را رد می‌کند.
- اپلیکیشن آزمایشی بدون مهاجرت‌های تولیدی، جدول‌های خالی را فقط روی دیتابیس موقت ایجاد می‌کند.
- از چهار فایل اکسل ساختگی، ورود و انتشار واقعی، تکرار شناسه رسمی در چند مجموعه، غیرفعال‌سازی مستقل و rollback را آزمایش می‌کند.
- اجرای این سناریو **هنوز تأیید نشده**؛ فقط بسته آماده و بررسی نحوی شده است.
- تنها مخزن متصل فعلی `psychoplan-hammasir-lite` است؛ این بسته را عمداً در مخزن ربات بارگذاری نکردیم.
- برای اجرا، محتویات ZIP را در یک **مخزن خصوصی مستقل و خالی** قرار دهید و از GitHub Actions -> PsychoPlan V16 isolated PostgreSQL QA -> Run workflow استفاده کنید.
- اگر تست سبز شد، باز هم قبل از نصب باید نسخه واقعی PostgreSQL، HTTPS، رفتار Frontend build و rollback کامل بررسی شوند.
